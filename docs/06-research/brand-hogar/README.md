# Marca Hogar — Research

Este directorio conserva investigaciones comerciales iniciadas desde Brand Candidates aprobados por Brand System.

La separación es intencional:

```text
Brand Candidate
→ Method v2
→ Research / evidencia / Product Bases
```

No debe confundirse este directorio con los research históricos organizados por nicho (`niche-001`, `niche-002`, `niche-003`).
