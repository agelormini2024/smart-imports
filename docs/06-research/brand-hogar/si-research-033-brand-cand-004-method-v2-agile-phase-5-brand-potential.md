## 2. Pregunta de F5

> ¿Puede Marca Hogar construir una propuesta coherente y defendible alrededor del monitoreo energético doméstico sin depender de private label superficial, features smart genéricas o claims de ahorro no demostrados?

## 3. Reglas metodológicas

```text
BRANDABILITY ≠ PRIVATE LABELABILITY

MORE CONNECTIVITY ≠ MORE BRAND POTENTIAL

APP / CLOUD / AI ≠ MOAT

MORE DATA ≠ MORE VALUE

DASHBOARD ≠ ACTIONABILITY

MEASUREMENT CLAIM ≠ VALIDATED ACCURACY

MONITORING ≠ SAVINGS
```

Una marca fuerte debe poder explicar:

```text
qué mide
→ dónde lo mide
→ con qué límites
→ cómo se instala
→ qué dato entrega
→ cómo se interpreta
→ qué acción habilita
→ qué NO puede concluirse del dato
```

## 4. Palancas de marca

### 4.1 Confianza en la medición

La categoría permite diferenciar por:

- magnitudes realmente medidas;
- rango eléctrico;
- corriente/potencia soportada;
- accuracy declarada y método de prueba;
- consistencia frente a distintos tipos de carga;
- persistencia y continuidad del dato.

La promesa no debe reducirse a `mide consumo`.

### 4.2 Compatibilidad local

Para Marca Hogar, la compatibilidad debe ser parte visible de la propuesta:

```text
220–240V / 50Hz
+ plug / formato local cuando corresponda
+ monofásico / trifásico
+ límite de corriente
+ espacio / montaje
+ seguridad eléctrica
```

Esto transforma una especificación técnica en reducción de fricción y riesgo para el cliente.

### 4.3 Instalación y onboarding

D1 tiene onboarding simple.

D2 agrega red/app.

D3/D4 pueden requerir tablero, CTs, identificación de circuitos, fases, bridge, Wi-Fi/Zigbee y eventualmente electricista.

La documentación, instalación guiada y soporte pueden ser parte del producto ampliado.

### 4.4 Del dato a una acción comprensible

El valor de marca aumenta si el dato responde preguntas concretas:

```text
¿cuánto consume este artefacto?
¿qué circuito explica este consumo?
¿cómo cambia mi consumo entre períodos?
¿hay un comportamiento inusual?
¿qué carga conviene revisar?
```

No se promete ahorro automático.

### 4.5 Continuidad y gobernanza del dato

En productos conectados deben distinguirse:

```text
medición local
histórico local
cloud obligatorio
exportación de datos
dependencia de plataforma
funcionamiento sin Internet
retención ante corte eléctrico
```

La continuidad del servicio puede ser una dimensión de marca, pero también una obligación de postventa.

### 4.6 Arquitectura de portfolio

El candidato permite una progresión coherente por boundary:

```text
artefacto
→ circuito / alimentación
→ hogar completo
→ múltiples circuitos
```

La marca no necesita comprometerse desde el inicio con todas las capas.

## 5. Lectura por cohort

### D1 — Plug-level standalone

```text
BRAND POTENTIAL: MEDIUM
```

Fortalezas:

- beneficio fácil de explicar;
- instalación simple;
- baja dependencia digital.

Debilidades:

- hardware muy replicable;
- bajo espacio para una marca basada sólo en el dispositivo;
- diferenciación depende de precisión, capacidad, memoria, compatibilidad y explicación.

### D2 — Smart plug + monitoring

```text
BRAND POTENTIAL: MEDIUM-HIGH — COMMODITY RISK
```

Fortalezas:

- demanda fuerte;
- uso cotidiano;
- automation/monitoring en un mismo punto.

Debilidades:

- Tuya/Smart Life y funciones smart están ampliamente replicadas;
- fuerte presión de precio;
- riesgo de private label superficial.

La marca debe distinguir `control` de `measurement` y evitar vender conectividad como innovación.

### D3 — DIN direct / hybrid

```text
BRAND POTENTIAL: HIGH — TECHNICAL TRUST
```

Fortalezas:

- job de medición/submedición claramente observable;
- posibilidad de construir credibilidad técnica;
- documentación e instalación generan valor real;
- uso doméstico, alquiler, circuito y pequeño comercio amplían el problema atendido.

Condiciones:

- seguridad;
- certificaciones;
- instalación;
- precisión;
- soporte;
- claims de protección cuando el producto sea híbrido.

### D4 — CT whole-home / multi-circuit

```text
BRAND POTENTIAL: HIGH — CONDITIONED BY SERVICE LAYER
```

Fortalezas:

- datos más ricos;
- extensión a solar/bidireccional y circuitos;
- potencial para análisis y automatización;
- mayor capacidad de construir ecosistema.

Condiciones:

- menor demanda visible;
- complejidad de instalación;
- dependencia de app/protocolo/plataforma;
- soporte y continuidad;
- mayor carga de onboarding.

## 6. Tesis de marca provisional

La oportunidad no es:

```text
“vender medidores”
```

sino potencialmente:

```text
hacer visible y comprensible el consumo eléctrico del hogar
→ con medición confiable
→ instalación compatible
→ datos interpretables
→ acciones concretas
→ soporte local
```

La arquitectura `territorio → misión → problema → solución → Product Base` permite incorporar este candidato dentro de Marca Hogar sin convertir la marca en una categoría de electrónica genérica.

## 7. Riesgos de marca

Los principales riesgos son:

- private label sin diferenciación;
- app genérica de terceros como única experiencia;
- dependencia de cloud no controlado;
- claims de ahorro no demostrados;
- claims de precisión sin evidencia;
- seguridad eléctrica;
- instalación deficiente;
- incompatibilidad de plug/fase/corriente;
- datos poco accionables;
- postventa técnica superior a la capacidad operativa inicial.
