# Marca Fitness — Exploración

## 1. Propósito

Explorar una futura marca orientada a Fitness reutilizando el mismo sistema empleado con Marca Hogar:

```text
territorio
→ misiones
→ problemas
→ soluciones
→ candidate hypotheses
→ Brand Candidate Screening
→ Method v2
```

Este frente existe para demostrar que el Brand System es reusable y no está acoplado al territorio Hogar.

## 2. Estado

```text
EXPLORATION
NO BRAND TERRITORY FROZEN
NO BRAND CANDIDATE PASSED
NO METHOD V2 OPENED
NO PURCHASE DECISION
```

El objetivo inmediato es contar con una lista razonada de hipótesis para discutir con el socio.

## 3. Hipótesis de territorio

Versión preliminar:

> **Ayudar a personas a entrenar, progresar y recuperarse mejor en contextos reales —especialmente hogar, espacios reducidos y rutinas no profesionales— mediante soluciones compactas, comprensibles y confiables.**

Esta definición no está aprobada ni congelada.

## 4. Principio

No partir de categorías comerciales como `mancuernas`, `bandas` o `pistolas de masaje`.

Partir de misiones y problemas del usuario.

## 5. Rutas de descubrimiento

Marca Fitness puede generar oportunidades por dos rutas:

```text
DESCENDENTE
territorio → misión → problema → solución

ASCENDENTE
producto descubierto → solución → problema → misión → territorio
```

Un producto recomendado, observado o atractivo puede ingresar mediante `SI-BRAND-003`, pero no se convierte automáticamente en Producto Base ni Brand Candidate.

Ambas rutas deben converger en `Brand Candidate Screening`.

Documento reusable: [`SI-BRAND-003 — Ingreso de oportunidades y descubrimiento`](../../si-brand-003-opportunity-intake-and-discovery.md).
